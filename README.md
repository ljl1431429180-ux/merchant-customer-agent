# 商家客服 Agent（作品集公开版）

面向电商商家的商品事实优先型客服 Agent。项目将店铺商品资料、飞鸽会话上下文和人工接管机制串为一条可控链路：**已确认的商品事实才允许自动回答；无法确认或涉及服务承诺的问题交给人工。**

> 本仓库为作品集公开版：不含真实店铺数据、客户会话、浏览器登录资料、线上部署绑定或任何密钥。

## 核心能力

- 商品同步与资料确认：将颜色、尺码、材质等商品详情整理为可被客服引用的知识。
- 会话上下文识别：优先绑定客户刚发送或刚浏览的商品；上下文不足时不猜测。
- 受控自动回复：仅回答已确认的低风险商品事实，如材质、颜色、尺码、库存与价格。
- 风险分流：物流时效、售后、尺码建议、资料缺失及商品不唯一时转人工。
- 飞鸽侧边栏：通过 Chrome 扩展在飞鸽工作台显示 Agent 状态、回复草稿和人工接管记录。

## 产品流程

```text
抖店商品同步 → 资料确认 → 客户提问
                         ↓
       商品/上下文识别 → 查询已确认商品事实
                         ↓
                低风险且信息充分？
                   ├─ 是：生成并发送受控回复
                   └─ 否：记录原因并转人工处理
```

## 技术结构

| 模块 | 作用 |
| --- | --- |
| `app/`、`components/` | 商家客服中心后台与 API |
| `lib/` | 商品事实清洗、问答决策、上下文匹配与权限控制 |
| `db/`、`drizzle/` | 商品、知识确认、会话与人工接管数据结构 |
| `chrome-extension/` | 飞鸽页面监听、Agent 面板与受控消息发送 |
| `scripts/` | 商品同步与资料处理的示例脚本 |

## 本地运行

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

需要模型能力时，在 `.env.local` 中填写你自己的 `QWEN_API_KEY`。请勿将 `.env.local` 上传到 GitHub。

## 安装扩展前的配置

在 `chrome-extension/background.js` 与 `chrome-extension/manifest.json` 中，把：

```text
https://your-dashboard.example.com
```

替换为你自己部署的后台地址，再在 Chrome 扩展管理页以“加载已解压的扩展程序”方式载入 `chrome-extension/`。

## 安全边界

- 不上传 `data/`、`profiles/`、Excel/CSV、日志、发布包或浏览器用户资料。
- 不提交 API Key、Cookie、会话 Token、部署绑定和私钥。
- 扩展仅在用户自己登录的工作台内运行；不应收集或上传客户隐私数据。
- 接入真实平台前，应遵守平台开放规则、商家授权范围及隐私要求。

## V1 范围

此版本重点验证“商品事实优先 + 风险转人工”的客服链路，不把它包装成能够覆盖所有售前、售后和物流问题的通用机器人。
